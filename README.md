# A 股尾盘筛选网页

## 启动方式

为避免浏览器出现 `127.0.0.1 拒绝连接 (ERR_CONNECTION_REFUSED)`，请先启动本地静态服务：

```bash
./start.sh
```

默认监听 `0.0.0.0:8080`，打开：

- `http://127.0.0.1:8080/index.html`（本机同环境访问）
- `http://<你的机器IP>:8080/index.html`（跨环境/端口映射访问）

## 端口和地址自定义

```bash
HOST=0.0.0.0 PORT=9000 ./start.sh
```

## 说明

- `index.html` 是纯前端页面。
- 如果不启动服务，直接打开不可达地址会出现“无法访问此页面”。
